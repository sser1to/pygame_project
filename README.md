# Abyss Walker

**Жанр:** Horror

**Игровой движок:** pygame

## Описание игры

**Преодолей все трудности и выживи**

Ты просыпаешься в заброшенной лаборатории, где что-то пошло не так. Свет мерцает, механизмы продолжают жить своей жуткой жизнью, а в темноте скрывается существо, которое с каждым уровнем становится умнее… и опаснее.

Твоя задача кажется простой: найти уголь, запустить печь и активировать нужные механизмы, чтобы выбраться. Но лаборатория не любит повторений - каждый новый уровень меняет расположение предметов, превращая знакомый путь в смертельную ловушку.

**7 уровней нарастающего кошмара**

С каждым этапом выживание становится сложнее:

- Монстр эволюционирует, открывая новые способы охоты: он начинает видеть, слышать и даже чувствовать твой запах.
- Темнота становится врагом: нельзя слишком долго находится в темноте.
— Голод не позволит расслабиться: ищи еду, иначе силы постепенно покинут тебя.
— Расположение рычагов и угля постоянно меняется, заставляя адаптироваться и принимать решения на ходу.

Каждый уровень — это новый баланс между страхом, исследованием и выживанием.

> Сможешь ли ты выбраться отсюда… пока что-то охотится на тебя в темноте?

## Механики

- Топливо для выживания
Ищи уголь, неси его к печи и активируй рычаги, чтобы продвигаться дальше. Но есть проблема - одновременно можно нести только один предмет, а каждое решение заставляет рисковать.
- Свет против темноты
Лаборатория поглощена холодными тенями. Без свечи тьма медленно замораживает тебя, превращая каждый темный коридор в смертельную ловушку.
- Голод не ждёт
Пока ты прячешься и исследуешь комплекс, силы постепенно уходят. Ищи еду и рассчитывай ресурсы.
- Живая процедурная карта
Уголь, рычаги, свечи, еда и темные зоны каждый раз появляются в новых местах. Нельзя запомнить маршрут - приходится адаптироваться.
- Монстр учится охотиться
Он слышит твои действия, чувствует запах, замечает движение и ищет тебя даже через стены. С каждым уровнем охотник становится умнее, а шансов скрыться - меньше.
- Свобода движения
Мир построен на сетке, но ты и монстр движетесь свободно - погони ощущаются живыми, резкими и непредсказуемыми.
- Напряжение растёт с каждым уровнем
Новые механики, больше угроз, меньше права на ошибку. То, что работало раньше - больше не спасёт.
- Существо, которое невозможно забыть
Огромная голова, длинные руки, цепляющиеся за стены и пол. Оно не ходит - оно подбирается к тебе.

## Сложные алгоритмы

1. Передвижение монстра

Используется flow-field навигация (потенциальное поле), построенная через многократный запуск Dijkstra по клеткам карты. В качестве целей подаются «сенсорные» точки: зрение, слух, обоняние и патрульные точки с разными весами. Поле пересчитывается раз в небольшой интервал, монстр выбирает следующий шаг по градиенту поля и движется с инерцией, что дает плавные траектории и устойчивое преследование даже при потере цели.

2. Рандомное появление предметов на карте

Используется best-candidate алгоритм (blue-noise/Poisson-disk-подобный). Для каждого предмета выбирается набор случайных кандидатных клеток и берется та, что максимально удалена от уже размещенных предметов того же типа и от стартовой позиции игрока. Дистанция жестко ограничена минимумом 25 клеток, а количество попыток контролируется параметрами спавна.

3. Заполнение карты темнотой

Темнота формируется из многослойного value-noise (fractal noise) с несколькими октавами и последующим сглаживанием клеточным автоматом. Сначала строится шумовая карта, затем берется верхний процент значений (в зависимости от уровня), после чего несколько проходов автомата соединяют зоны и устраняют одиночные артефакты. Это дает связные «живые» области тьмы без повторяемого шаблона.

## Как начать

1. Клонируем репозиторий

```bash
git clone https://github.com/sser1to/pygame_project
```

2. Создаем виртуальное окружение

```bash
python -m venv venv
```

3. Активируем виртуальное окружение

- Windows PowerShell:

```bash
venv\Scripts\Activate.ps1
```

- Windows cmd:

```bash
venv\Scripts\activate
```

- Linux/macOS:

```bash
source venv/bin/activate
```

4. Устанавливаем зависимости

```bash
pip install -r requirements.txt
```

5. Запускаем игру

```bash
python main.py
```

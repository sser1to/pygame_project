# Abyss Walker

**Жанр:** Roguelike / Dungeon crawler

## Сложные алгоритмы, которые нужно обязательно реализовать в проекте

1. Генерация карты (пещеры, коридоры)
2. Генерация пещер (Cellular Automata)
3. Поиск игрока врагами (преследование игрока)

## Описание игры

Игрок появлятся в стартовой пещере, где он получает стандартное оружие (стандартный меч и стандартный щит). Ему предстоит найти выход из пещеры, проходя через толпы монстров, большое количество коридоров и пещер. По пути игрок может находить сундуки, в которых может выпасть зелье лечения, новое снаряжение или сундук может оказаться мимиком.

## Механики

- Игрок передигается с помощью WASD и стрелочек
- Игрок может атакаовать при нажатии на Enter
- Игрок каждые 2 секунды может делать рывок на Space (быстрое передвижение на 2 клетки)
- Карта состоит из клеток, но игрок и враги могут двигаться по ней свободно (жестко не привязаны к клеткам)
- Каждый раз уровень генерируется уникально, а выход генерируется примерно в 10 комнатах от начальной локации
- При перемещении в новую комнату в ней появляются враги, которые начинают преследовать и атаковать врага, также они могут перемещаться между комнатами
- Игроку на экране показывается только текущая команта, при переходе в другую комнату происходит быстрый переход со сменой комнаты
- Игрок может находить более сильное снаряжение, что увеличивает его характеристики
- У игрока есть следующие характеристики:
    1. Здоровье (не может быть улучшено, но может быть восстановлено с помощью Зелья Лечения)
    2. Защита (уменьшает урон по игроку, улучшается при нахождении более сильного щита)
    3. Урон (урон по врагам, улучшается при нахождении более сильного меча)
